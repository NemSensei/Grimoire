# Projet : Le Grimoire

## But
Solution web de knowledge base pour une équipe de pentest.
Fiches en Markdown organisées par dossiers thématiques (web, AD, network, privesc…). Le projet est l'outil de web app de knowledge base simple. Sa finalité est d'être déployé sur un de nos serveur, que chaque membre de l'équipe puisse s'y connecter voir les fiches, les modifiers, uploader les siennes, gérer les dossiers et l'arborescence 

## Contraintes
- Rendu type wiki, navigation simple entre les fiches
- Recherche full-text dans les fiches
- Multi utilisateurs
- Rester simples
